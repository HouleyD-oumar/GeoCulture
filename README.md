# GeoCulture React

GeoCulture React is a modern rebuild of the GeoCulture project, featuring enhanced UI and functionality. This application is dedicated to learning about countries and cultures around the world through interactive quizzes and information.

## Features

- **Modern UI**: Built with Material-UI for a sleek, responsive design
- **Interactive Maps**: Explore countries with interactive maps
- **Country Information**: Detailed information about countries including flags, capitals, languages, and more
- **Quiz System**: Test your knowledge with various quiz modes
- **Favorites**: Save your favorite countries for quick access
- **Offline Support**: Basic functionality works offline
- **Responsive Design**: Works on all devices from mobile to desktop

## Technology Stack

- React
- Material-UI
- React Router
- Axios for API calls
- MapBox for interactive maps
- Local Storage for offline data

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

- `/src/components`: Reusable UI components
- `/src/pages`: Main application pages
- `/src/services`: API and data services
- `/src/hooks`: Custom React hooks
- `/src/utils`: Utility functions
- `/src/assets`: Static assets like images
- `/src/context`: React context providers
