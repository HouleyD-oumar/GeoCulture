# Services Directory

This directory contains service modules for the GeoCulture application.

Services handle data fetching, API calls, and other business logic separate from UI components.

Main services include:
- CountryService: Fetches country data from APIs
- FavoritesService: Manages user favorites
- QuizService: Handles quiz logic and scoring
- AuthService: Manages user authentication
- StorageService: Handles local storage for offline functionality
